# ❤️ Heart & Stroke Prediction

A Machine Learning based web application that predicts the possibility of heart disease using multiple medical parameters. The trained Machine Learning model is integrated with a Streamlit web application to provide an interactive prediction experience.

## 🚀 Live Demo

[Click here to try the Live Demo](https://heart-stroke-prediciton-9fatavmhhrwmnirh68n8sm.streamlit.app/)

## 📌 Project Overview

This project demonstrates an end-to-end Machine Learning workflow, starting from data analysis and preprocessing to model training and deployment.

The major steps performed in this project are:

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Feature encoding
- Feature scaling
- Feature selection
- Model training
- Model evaluation
- Model comparison
- Model serialization using Joblib
- Streamlit application development
- Cloud deployment

## 🤖 Machine Learning Models

I trained and evaluated five different Machine Learning classification models:

1. Logistic Regression
2. Support Vector Machine (SVM)
3. Decision Tree
4. Naive Bayes
5. K-Nearest Neighbors (KNN)

After training and comparing the models, **KNN was selected as the final model for deployment**.

The trained KNN model was saved using Joblib and integrated into the Streamlit application.

## 🧠 Input Features

The application uses the following medical parameters:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak (ST Depression)
- ST Slope
