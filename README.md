# Heart Disease Prediction

A Machine Learning web application that predicts the possibility of heart disease based on medical parameters.

## Features

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope

## Machine Learning Model

This project uses a K-Nearest Neighbors (KNN) classification model.

The trained model and preprocessing objects are saved using Joblib.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
